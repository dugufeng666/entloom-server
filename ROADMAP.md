# Entloom Server Roadmap

## Foundation

- [x] Spring Boot 4.1.2 and Java 25 baseline
- [x] Modular-monolith package direction
- [x] Docker Compose development environment
- [x] Health endpoint and API version namespace
- [ ] CI build and dependency security checks

## B1: ontology workspace

- [ ] Project and model version APIs
- [ ] Classes, attributes and relations
- [ ] Version conflict protection
- [ ] OpenAPI contract and generated client flow

## B2: data and evidence

- [ ] CSV import preview and atomic commit
- [ ] Reference and duplicate checks
- [ ] Source and evidence records
- [ ] Parameterized query execution with limits

## Later

- [ ] Agent tool registry and controlled actions
- [ ] Async imports and long-running jobs
- [ ] Tenant administration and enterprise connectors

Roadmap items are targets, not promises of a release date.
